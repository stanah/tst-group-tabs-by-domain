TST Auto Grouper 設定

LLMを使用したタブの自動グループ化機能の設定

API Key設定

Claude APIを使用するには、Anthropic APIキーが必要です。 Anthropic Console から取得できます。

APIキーは安全に保存され、このブラウザ内でのみ使用されます

モデル設定

Haikuモデルは高速で低コストです。より高度な分析にはSonnetやOpusを選択してください

グループ化設定

手動グループ化ボタンでLLMによる分析を使用します

指定した間隔で自動的にタブをグループ化します

自動グループ化を実行する間隔（5分〜1440分）

この数以上のタブがある場合にグループ化を実行します
